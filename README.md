# Kingdomino · простий підрахунок

Статичний помічник очок для класичного Kingdomino (5×5). Українською. Без бекенду.

UI: [Pico.css](https://picocss.com/) з CDN + легка власна тема (луг / ліс).

## Що вміє v1

- стіл на 2–4 гравців (за замовчуванням 2 готові)
- підрахунок областями: місцевість + клітинки × корони (поля видно одразу)
- порівняння / хто лідирує
- localStorage з TTL 1 доба, автозбереження, «Скинути» + підтвердження
- короткі правила

## Локально

З кореня репозиторію:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Відкрийте [http://127.0.0.1:8080](http://127.0.0.1:8080).

Або просто відкрийте `index.html` у браузері.
